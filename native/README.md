# 沉星画笔 · 游戏内模块

v0.4.1 支持键盘移动与鼠标绘图并行：进入绘图前按住的移动键继续生效，绘图期间普通键盘输入继续交给游戏。鼠标与插件快捷键由画笔处理；打开插件设置时拦截游戏输入。

v0.3.0 新增独立离线安装器和游戏内插件设置。先退出游戏，运行项目根目录 `SinkingStarPainter-Setup.exe` 安装或更新，再启动游戏。安装器可单独分发，支持 Steam 目录检测、手动选择、更新备份和卸载。

点击工具栏齿轮“设置”打开游戏内“插件设置”，勾选或取消“启用画笔插件”，立即生效并保存。禁用后工具栏和笔迹隐藏，F9 停用；禁用时按 **F8** 可打开设置重新启用插件。配置位于数据目录的 `plugin-settings.ini`，卸载保留设置和笔迹。这是独立的游戏内面板，不是游戏原生设置菜单中的条目。

v0.2.4 将“画笔 F8”收起入口和展开竖栏都固定到左上角（距顶部 12 像素），每项增加金色线描小图标并保留中文。图标直接用矢量线条绘制，不依赖图标字体；工具栏仍宽 76 像素。

v0.2.3 修复竖栏中文标签在代码写入时损坏为问号的问题，同时消除由重名标签引起的按钮标识冲突。F8 可重新唤出绘图栏，F9 控制整体显隐。

工具栏现固定在屏幕最左侧，宽 76 像素，所有工具纵向单列排列。点击“墨色”向右展开颜色和笔触设置，点击“完成”收回设置。短屏幕可在栏内滚动；退出绘图后只显示“画笔 / F8”小入口。保持同款字体与金橙配色。

界面以游戏原生暂停菜单为参考：读取游戏安装目录中的 `SourceHanSerifCN-SemiBold.otf`，搭配金橙文字、浅金选中态、半透明蓝绿色面板。去掉开发工具标题栏和蓝色按钮，使用文字按钮、简洁色点和轻分隔线。收起时只保留一行快捷键提示。字体不随插件分发，缺少游戏字体时回退到系统宋体。

本版是加载到 `sinking_star.exe` 进程内的 DirectX 12 模块。画笔和工具栏直接绘制到游戏交换链，不需要启动旧版桌面助手，也不需要截帧进入编辑器。

## 当前电脑已经安装

安装目录：`D:\Program Files (x86)\Steam1\steamapps\common\Order of the Sinking Star`。

从 Steam 正常启动《沉星之序》，左上角会出现“F8 画笔”提示。旧版 `SinkingStarAssistant.exe` 不要同时运行，否则其全局 F8/F9 热键可能冲突。

| 操作 | 按键 / 按钮 |
| --- | --- |
| 进入 / 退出绘图 | F8 |
| 隐藏 / 显示工具栏和全部标注 | F9 |
| 退出绘图，保留标注显示 | Esc 或“完成绘图” |
| 绘制 | 绘图模式中按住鼠标左键拖动 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y，或对应按钮 |
| 工具栏位置 | 固定屏幕最左侧 |
| 保存 / 恢复 | 工具栏“保存” / “恢复” |

画笔包括自由线、直线、箭头、矩形、圆圈、编号、整笔橡皮。清空也可以撤销。绘图时可用键盘移动角色；退出绘图后，线条仍显示，鼠标恢复交给游戏。切出游戏时退出绘图。

**不暂停游戏。** 标注固定在屏幕上，镜头变化时不会跟随场景；切关后应清空或隐藏。保存使用归一化屏幕坐标，分辨率变化时随画面缩放。第一版只保存一个槽位，保存会替换上一份标注，不自动按关卡归档。

数据目录：`%LOCALAPPDATA%\SinkingStarAssistant\native`。

- `last-drawing.ssp`：可恢复的标注。
- `overlay.log`：加载、渲染初始化和异常日志。

## 安装 / 停用

先关闭游戏。运行 PowerShell 脚本：

```powershell
./install.ps1
./disable.ps1
```

其他安装位置使用 `-GameDirectory '完整游戏目录'` 参数。

安装只新增 `dxgi.dll` 和安装清单，不覆盖游戏 exe。遇到不属于本插件的同名 DLL 会拒绝覆盖。停用会核对安装清单的 SHA256，将本插件的 DLL 改名保留，下一次启动游戏即不加载插件。更新时先关闭游戏，再执行安装脚本；上一版 DLL 会备份。

如果游戏无法启动，可关闭游戏后使用停用脚本。不要在游戏运行时强行卸载 DLL。

## 技术说明

游戏动态加载 DXGI；代理转发到系统目录中的 DXGI 实现，拦截工厂创建的 DX12 交换链，在 Present 前提交独立绘制命令，使用独立描述符堆、命令分配器和 GPU fence。绘图时通过窗口消息和主程序 GetAsyncKeyState 导入过滤接管键鼠输入。渲染异常时停用画笔并记录日志。

使用 Dear ImGui v1.91.9b（MIT），固定提交 `f5befd2d29e66809cd1110a152e375a7f1981f06`。许可证随发布包提供。

当前没有实现游戏逻辑暂停、单帧推进、输入掐帧或视频逐帧回看。这些需要单独调查游戏逻辑，不能用冻结渲染冒充。

## 构建

需要 Visual Studio 2022 C++ 工具链、.NET SDK（用于恢复官方 Windows SDK NuGet 包）和 Git。

```powershell
./build-native.ps1
```

输出位于 `dist/SinkingStarInGame`。不需要安装旧 WPF 程序。
